📋 O QUE VOCÊ TEM AGORA

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔲 QR CODE
   • Gerar QR de qualquer texto/link/senha
   • Modelos prontos: Wi-Fi, E-mail, Telefone, Contato, SMS
   • Ajuste correção de erro (L, M, Q, H)
   • Mude cores e tamanho
   • Salvar como PNG


🔐 HASH SHA-256 / SHA-512
   • Gerar hash de textos ou arquivos
   • Verificar integridade de arquivos
   • Comparar hash com texto original
   • Garantir que arquivo não foi corrompido


📤 TRANSMITIR ARQUIVO
   • Por QR Code: divide arquivo em múltiplos QRs
   • Por Som: emite ondas sonoras (FSK)
   • Suporta: imagens, músicas, vídeos, documentos
   • Arquivos de qualquer tamanho!


📥 RECEBER ARQUIVO
   • Por Câmera: escaneia QR codes automaticamente
   • Por Microfone: decodifica som FSK
   • Reconstrói arquivo automaticamente
   • Baixe o arquivo recebido


💡 TRANSMISSÃO POR LUZ
   • Transmite dados variando brilho da tela
   • Silencioso (não emite som)
   • Receptor usa câmera para captar
   • Funciona no escuro


🔊 TRANSMISSÃO POR SOM (FSK)
   • Como um modem antigo
   • 800Hz = bit 0, 1600Hz = bit 1
   • Funciona através de paredes!
   • Receba por microfone

💡 EXEMPLOS PRÁTICOS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. COMPARTILHAR WI-FI:
   • Clique em "📶 Wi-Fi"
   • Mude nome e senha
   • Gere QR code
   • Visitante escaneia e conecta automaticamente!


2. VERIFICAR ARQUIVO:
   • Gere hash SHA-256 do arquivo
   • Envie arquivo + hash separadamente
   • Destinatário verifica se arquivo não foi corrompido


3. TRANSFERIR ARQUIVO SEM INTERNET:
   • Selecione arquivo
   • Gere QR codes (divide automaticamente)
   • Receptor escaneia todos
   • Arquivo reconstruído!


4. TRANSMITIR POR SOM:
   • Digite texto
   • Clique em "▶️ Transmitir"
   • Programa emite sons
   • Receptor usa microfone
   • Dados decodificados!


5. BACKUP DE SENHAS:
   • Digite senhas importantes
   • Gere QR code
   • Imprima e guarde em local seguro
   • Backup físico, impossível de hackear

📊 VELOCIDADE DE TRANSMISSÃO

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌──────────────────┬──────────────┬──────────────────────────────────────────┐
│ Método           │ Velocidade   │ Tempo para 1MB                         │
├──────────────────┼──────────────┼──────────────────────────────────────────┤
│ QR Code          │ ~3KB/QR      │ Rápido (poucos QRs)                    │
│ Som (FSK)        │ ~20 bits/s   │ ~11 horas (MUITO LENTO)                │
│ Luz              │ ~10 bits/s   │ ~22 horas (MUITO LENTO)                │
│ Vídeo            │ ~3KB/frame   │ ~5 minutos (30 FPS)                    │
└──────────────────┴──────────────┴──────────────────────────────────────────┘

RECOMENDAÇÃO:
• Arquivos pequenos (<10KB): Use QR Code
• Arquivos médios: Use QR Code com "Reproduzir Sequência"
• Arquivos grandes: Divida em partes menores

🐛 PROBLEMAS COMUNS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

QR Code não gera:
→ Texto muito longo → Use correção L ou divida

Som não recebido:
→ Aumente volume, aproxime dispositivos
→ Use fones de ouvido para transmitir

Luz não recebida:
→ Escureça ambiente ou aproxime dispositivos
→ Aumente contraste

Câmera não funciona:
→ Permita acesso à câmera no navegador
→ Use transmissão manual (copiar/colar QR codes)

Arquivo não reconstrói:
→ Escaneie QR codes na ordem correta (1/10, 2/10, 3/10...)
→ Use transmissão por som ou luz
