📋 AS 6 FUNCIONALIDADES

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ QR CODE (Aba: 📱 QR Code)
   ✓ Gera QR Codes de qualquer texto/link
   ✓ 4 níveis de correção de erro
   ✓ Cores personalizáveis
   ✓ Modelos prontos (Wi-Fi, E-mail, etc.)


2️⃣ HASH SHA-256/512 (Aba: 🔐 Hash SHA)
   ✓ Calcula hashes de texto ou arquivos
   ✓ Verifica integridade comparando hashes
   ✓ Usa Web Crypto API nativa


3️⃣ ARQUIVO→QR (Aba: 📁 Arquivo→QR)
   ✓ Divide arquivos em múltiplos QR Codes
   ✓ Transmite imagens, músicas, vídeos
   ✓ Reconstrói o arquivo no receptor


4️⃣ SOM (Aba: 🔊 Som)
   ✓ Transmite dados por áudio (modem)
   ✓ Frequências: 800Hz (bit 0) e 1200Hz (bit 1)
   ✓ Recepção via microfone
   ✓ 3 velocidades: lenta, média, rápida


5️⃣ LUZ (Aba: 💡 Luz)
   ✓ Transmite dados pela tela
   ✓ Branco = bit 1, Preto = bit 0
   ✓ Recepção via câmera
   ✓ Velocidade ajustável


6️⃣ CÂMERA (Aba: 📷 Câmera)
   ✓ Lê QR Codes pela câmera
   ✓ Captura vídeo em tempo real
   ✓ Pronto para integrar jsQR

🎯 EXEMPLOS DE USO

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EXEMPLO 1: Transferir Arquivo por QR
─────────────────────────────────────
Dispositivo A:
1. Aba "📁 Arquivo→QR"
2. Selecione foto.jpg
3. Gere os QR Codes
4. Mostre cada QR na tela

Dispositivo B:
1. Aba "📷 Câmera"
2. Escaneie cada QR na ordem
3. Concatene os dados
4. Arquivo reconstruído!


EXEMPLO 2: Transferir Senha por Som
─────────────────────────────────────
Dispositivo A:
1. Aba "🔊 Som"
2. Digite: "MinhaSenha123"
3. Velocidade: Lenta
4. Clique em "🔊 Transmitir"

Dispositivo B:
1. Aba "🔊 Som"
2. Clique em "🎤 Escutar"
3. Aproxime do dispositivo A
4. Senha recebida!


EXEMPLO 3: Transferir Texto por Luz
─────────────────────────────────────
Dispositivo A:
1. Aba "💡 Luz"
2. Digite: "Mensagem Secreta"
3. Velocidade: 150ms
4. Clique em "💡 Transmitir"

Dispositivo B:
1. Aba "💡 Luz"
2. Clique em "📷 Iniciar Câmera"
3. Aponte para a tela do A
4. Mensagem recebida!


EXEMPLO 4: Verificar Integridade
─────────────────────────────────────
1. Baixe um arquivo da internet
2. Aba "🔐 Hash"
3. Arraste o arquivo
4. Copie o hash SHA-256
5. Compare com o hash oficial
6. Se iguais = arquivo íntegro!

🔧 COMO FUNCIONA TECNICAMENTE

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

AUDIO MODEM (FSK):
• FSK = Frequency Shift Keying
• Bit 0 = 800Hz
• Bit 1 = 1200Hz
• Transmissor: Web Audio API (oscilador)
• Receptor: Web Audio API (analyser + FFT)

LIGHT MODEM (OOK):
• OOK = On-Off Keying
• Bit 0 = Preto (0% brilho)
• Bit 1 = Branco (100% brilho)
• Transmissor: Mudar background-color
• Receptor: getUserMedia + análise de brilho

FILE OVER QR:
• Converte arquivo para Base64
• Divide em chunks de 150 caracteres
• Cada chunk vira um QR Code
• Receptor escaneia e concatena
• Converte Base64 de volta para arquivo
