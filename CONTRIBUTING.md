# Guia de Contribuição - Projeto Jyy 🌐

O **Jyy** é um projeto de código aberto (Open Source), livre e comunitário. Qualquer pessoa no mundo pode visualizar o código-fonte, clonar, sugerir modificações, adicionar novos protocolos físicos e melhorar o sistema.

---

## 🤝 Como Modificar e Contribuir

### 1. Fazer um Fork do Projeto
No GitHub, clique no botão **Fork** no canto superior direito para criar uma cópia do projeto na sua própria conta.

### 2. Clonar localmente
```bash
git clone https://github.com/SEU-USUARIO/jyy.git
cd jyy
```

### 3. Instalar dependências e Rodar localmente
```bash
npm install
npm run dev
```

### 4. Criar uma Branch para sua melhoria
```bash
git checkout -b minha-nova-funcionalidade
```

### 5. Fazer alterações e Commit
```bash
git add .
git commit -m "feat: adicionado suporte ao protocolo X"
```

### 6. Enviar para seu GitHub e abrir um Pull Request
```bash
git push origin minha-nova-funcionalidade
```
No GitHub, abra um **Pull Request (PR)** para a branch principal (`main`). Analisaremos e integraremos suas alterações!

## 🛡️ Regras da Comunidade e Princípios
1. **Privacidade First**: Manter a proteção de dados dos usuários (erro deliberado de ~10 km na geolocalização no Globo 3D).
2. **Descentralização**: Nenhum nó centralizador ou ponto único de falha.
3. **Código Aberto & Transparente**: Sem backdoors ou telemetria invasiva.
4. **Respeito & Cooperação**: A internet livre é construída em comunidade.
