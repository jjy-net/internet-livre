# 🎯 Gerador de QR Code - Solução para Idosos

## ✅ SOLUÇÃO FINAL - Super Simples!

Para uma pessoa idosa usar, você precisa entregar **APENAS 2 ARQUIVOS**:

```
📁 Pasta do Programa
├── 📄 QR-Code.bat          ← O idoso clica AQUI (duplo clique)
├── 📄 QR-Code-App.html     ← (este fica junto, não precisa mexer)
└── 📄 GUIA_VISUAL.txt      ← (opcional - instruções com figuras)
```

---

## 🚀 COMO FUNCIONA

### Para o IDOSO:
1. **Dê duplo clique** em `QR-Code.bat`
2. Uma janela bonita abre (sem barra de navegador!)
3. Digite o que quer no QR Code
4. Clique em "Gerar QR Code"
5. Clique em "Salvar Imagem"
6. **Pronto!**

### O que acontece por trás:
- O `.bat` abre o `.html` em **modo aplicativo** do Edge/Chrome
- A janela abre **sem barra de endereço** (parece um programa!)
- Funciona **100% offline**
- **Não dispara antivírus** (é apenas HTML + batch)

---

## 📦 COMO DISTRIBUIR

### Opção 1: Pendrive
1. Copie os 3 arquivos para um pendrive
2. Entregue o pendrive para o idoso
3. Ele conecta o pendrive e dá duplo clique no `.bat`

### Opção 2: Área de Trabalho
1. Copie os 3 arquivos para a Área de Trabalho
2. Crie um atalho do `.bat` (botão direito → Enviar para → Área de trabalho)
3. O idoso clica no atalho e pronto!

### Opção 3: E-mail
1. Comprima os 3 arquivos em um ZIP
2. Envie por e-mail
3. O idoso extrai e usa

## 💡 DICAS PARA IDOSOS

### Criar Atalho na Área de Trabalho:
1. Clique com botão direito no `QR-Code.bat`
2. Selecione "Enviar para" → "Área de trabalho (criar atalho)"
3. Pronto! Agora tem um ícone na área de trabalho

### Renomear o Atalho:
1. Clique com botão direito no atalho
2. Selecione "Renomear"
3. Digite: "Meu QR Code" (ou o nome que quiser)

### Fixar na Barra de Tarefas:
1. Clique com botão direito no `QR-Code.bat`
2. Selecione "Fixar na barra de tarefas"
3. Pronto! Agora tem um botão fixo na barra inferior

## 🆘 SOLUÇÃO DE PROBLEMAS

### O arquivo não abre?
→ Clique com botão direito → "Abrir com" → Microsoft Edge

### O QR Code não aparece?
→ Verifique se digitou algo na caixa de texto

### Não consigo salvar?
→ Tente salvar na Área de Trabalho (é mais fácil de encontrar)

### O antivírus reclamou?
→ Isso NÃO deve acontecer! Se acontecer, use o arquivo `.hta` em vez do `.bat`
