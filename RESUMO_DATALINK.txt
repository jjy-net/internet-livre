✅ O QUE FOI CRIADO

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Um programa COMPLETO com 6 funcionalidades principais:

1. 🔲 QR Code
   • Gerar QR codes de qualquer texto/link/senha
   • Modelos prontos (Wi-Fi, E-mail, Telefone, etc.)
   • Ajuste correção de erro, cores, tamanho
   • Salvar como PNG

2. 🔐 Hash SHA-256 / SHA-512
   • Gerar hash de textos ou arquivos
   • Verificar integridade de arquivos
   • Comparar hash com texto original

3. 📤 Transmitir Arquivo
   • Por QR Code (divide arquivo em múltiplos QRs)
   • Por Som (FSK - modulação de frequência)
   • Suporta: imagens, músicas, vídeos, documentos

4. 📥 Receber Arquivo
   • Por Câmera (escaneia QR codes)
   • Por Microfone (decodifica som FSK)
   • Reconstrói arquivo automaticamente

5. 💡 Transmissão por Luz
   • Transmite dados variando brilho da tela
   • Silencioso (não emite som)
   • Receptor usa câmera para captar

6. 🔊 Transmissão por Som (FSK)
   • Como um modem antigo
   • 800Hz = bit 0, 1600Hz = bit 1
   • Funciona através de paredes!

QR CODE:
--------
• Digite qualquer texto
• Clique em "⚡ Gerar QR Code"
• Salve como PNG
• Use modelos prontos (Wi-Fi, E-mail, etc.)


HASH:
-----
• Digite texto ou selecione arquivo
• Clique em "🔒 SHA-256" ou "🔐 SHA-512"
• Copie o hash gerado
• Verifique integridade de arquivos


TRANSMITIR ARQUIVO:
-------------------
• Selecione arquivo (imagem, música, vídeo)
• Clique em "📤 Gerar QR Codes"
• Arquivo é dividido em múltiplos QR codes
• Receptor escaneia todos e reconstrói


RECEBER ARQUIVO:
----------------
• Clique em "📷 Iniciar Câmera"
• Aponte para QR codes
• Arquivo é reconstruído automaticamente
• Baixe o arquivo recebido


TRANSMISSÃO POR SOM:
--------------------
• Digite texto
• Clique em "▶️ Transmitir"
• Programa emite sons (FSK)
• Receptor usa microfone para captar


TRANSMISSÃO POR LUZ:
--------------------
• Selecione arquivo
• Clique em "▶️ Iniciar Transmissão"
• Tela pisca branco/preto
• Receptor usa câmera para captar

📊 VELOCIDADE DE TRANSMISSÃO

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌──────────────────┬──────────────┬──────────────────────────────────────────┐
│ Método           │ Velocidade   │ Tempo para 1MB                         │
├──────────────────┼──────────────┼──────────────────────────────────────────┤
│ QR Code          │ ~3KB/QR      │ Rápido (poucos QRs)                    │
│ Som (FSK)        │ ~20 bits/s   │ ~11 horas (MUITO LENTO)                │
│ Luz              │ ~10 bits/s   │ ~22 horas (MUITO LENTO)                │
│ Vídeo            │ ~3KB/frame   │ ~5 minutos (30 FPS)                    │
└──────────────────┴──────────────┴──────────────────────────────────────────┘

RECOMENDAÇÃO:
• Arquivos pequenos (<10KB): Use QR Code
• Arquivos médios: Use QR Code com "Reproduzir Sequência"
• Arquivos grandes: Divida em partes menores

💡 EXEMPLOS PRÁTICOS

1. COMPARTILHAR WI-FI:
   • Clique em "📶 Wi-Fi"
   • Mude nome e senha
   • Gere QR code
   • Visitante escaneia e conecta!

2. VERIFICAR ARQUIVO:
   • Gere hash SHA-256 do arquivo
   • Envie arquivo + hash separadamente
   • Destinatário verifica integridade

3. TRANSFERIR SEM INTERNET:
   • Selecione arquivo
   • Gere QR codes
   • Receptor escaneia
   • Arquivo reconstruído!

4. BACKUP DE SENHAS:
   • Digite senhas importantes
   • Gere QR code
   • Imprima e guarde
   • Backup físico seguro!

→ Permita acesso no navegador

→ Escaneie QR codes na ordem correta
