OPÇÃO 1: Copiar a pasta dist inteira
─────────────────────────────────────────

1. Copie a pasta: dist\
2. Cole em qualquer lugar (pendrive, área de trabalho, etc.)
3. Dê duplo clique em: dist\index.html
4. Funciona!


OPÇÃO 2: Criar um atalho
─────────────────────────────────────────

1. Clique com botão direito em: dist\index.html
2. Selecione: "Enviar para" → "Área de trabalho (criar atalho)"
3. Pronto! Tem um atalho na área de trabalho


OPÇÃO 3: Usar o arquivo .bat
─────────────────────────────────────────

1. Copie: public\Abrir-App.bat
2. Cole na área de trabalho
3. Dê duplo clique
4. Funciona!

─────────────────────────────────

1. Abra o app
2. Digite: https://www.google.com
3. Clique em "Gerar QR Code"
4. Clique em "Baixar PNG"
5. Pronto!


EXEMPLO 2: QR Code para Wi-Fi
─────────────────────────────────

1. Abra o app
2. Clique no botão "📶 Wi-Fi"
3. Mude "NomeDaRede" para o nome do seu Wi-Fi
4. Mude "Senha" para a senha do seu Wi-Fi
5. Clique em "Gerar QR Code"
6. Pronto!


EXEMPLO 3: QR Code com telefone
─────────────────────────────────

1. Abra o app
2. Clique no botão "📱 Telefone"
3. Mude o número para o seu telefone
4. Clique em "Gerar QR Code"
5. Pronto!

Problema: O arquivo .bat não funciona
Solução:  Abra direto o arquivo: dist\index.html


Problema: O QR Code não aparece
Solução:  Verifique se digitou algo na caixa de texto


Problema: Não consigo salvar
Solução:  Clique em "Baixar PNG" ou "Baixar SVG"


Problema: O antivírus reclamou
Solução:  Isso NÃO deve acontecer! É apenas um arquivo HTML
