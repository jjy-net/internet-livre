## 📋 PASSO A PASSO

### 1️⃣ Abrir o Arquivo

**No Windows:**
```
1. Navegue até a pasta: public/
2. Clique com botão direito em: DataLink-BASICO.html
3. Selecione: "Abrir com" → "Google Chrome" (ou Edge/Firefox)
```

**No Android:**
```
1. Copie o arquivo DataLink-BASICO.html para o celular
2. Abra com Chrome ou Firefox
```

### 2️⃣ Fazer Login

```
1. Digite seu nome (ex: João)
2. Digite uma senha (mínimo 8 caracteres)
   Exemplo: Teste123!
3. Confirme a senha (digite a mesma)
4. Clique em "ENTRAR"
```

### 3️⃣ Usar o Chat

```
1. Digite uma mensagem
2. Pressione Enter ou clique em "ENVIAR"
3. A mensagem aparece na tela
```

## 🐛 SE NÃO FUNCIONAR

### Problema 1: "Não inicia após colocar nome e senha"

**Solução:**
```
1. Abra o Console do Navegador (F12)
2. Vá na aba "Console"
3. Tente fazer login
4. Veja se aparece algum erro
5. Me envie a mensagem de erro
```

### Problema 2: "Aparece tela em branco"

**Solução:**
```
1. Recarregue a página (F5)
2. Limpe o cache do navegador
3. Tente outro navegador (Chrome, Firefox, Edge)
```

### Problema 3: "Botão ENTRAR não faz nada"

**Solução:**
```
1. Abra o Console (F12)
2. Procure por erros em vermelho
3. Me envie a mensagem de erro
```
