PASSO 1: Dê duplo clique em "QR-Code.bat"
         ↓
PASSO 2: Uma janela bonita abre (sem barra de navegador!)
         ↓
PASSO 3: Digite o que quer no QR Code
         ↓
PASSO 4: Clique em "⚡ Gerar QR Code"
         ↓
PASSO 5: Clique em "💾 Salvar Imagem"
         ↓
PASSO 6: Pronto!

💡 COMO FUNCIONA POR TRÁS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

O arquivo .bat:
1. Procura o Microsoft Edge no computador
2. Abre o arquivo HTML em "modo aplicativo"
3. O Edge abre SEM barra de endereço (parece um programa!)
4. Se não tiver Edge, usa Chrome
5. Se não tiver nenhum, abre o arquivo HTA (nativo Windows)

Resultado: O idoso vê uma janela bonita como se fosse um programa normal!

OPÇÃO 1: Pendrive (Recomendado)
─────────────────────────────────
1. Copie os 2 arquivos para um pendrive
2. Entregue o pendrive
3. O idoso conecta e dá duplo clique no .bat


OPÇÃO 2: Área de Trabalho
─────────────────────────────────
1. Copie os 2 arquivos para a Área de Trabalho
2. Crie um atalho do .bat (botão direito → Enviar para → Área de trabalho)
3. O idoso clica no atalho


OPÇÃO 3: E-mail
─────────────────────────────────
1. Comprima os 2 arquivos em um ZIP
2. Envie por e-mail
3. O idoso extrai e usa

📋 EXEMPLOS DE USO

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EXEMPLO 1: QR Code para um site
─────────────────────────────────
1. Digite: https://www.google.com
2. Clique em "Gerar QR Code"
3. Salve a imagem
4. Pronto!


EXEMPLO 2: QR Code para Wi-Fi
─────────────────────────────────
1. Clique no botão "📶 Wi-Fi"
2. Mude "NomeDaRede" para o nome do seu Wi-Fi
3. Mude "Senha" para a senha do seu Wi-Fi
4. Clique em "Gerar QR Code"
5. Pronto!


EXEMPLO 3: QR Code com telefone
─────────────────────────────────
1. Clique no botão "📱 Telefone"
2. Mude o número para o seu telefone
3. Clique em "Gerar QR Code"
4. Pronto!

🔧 DICAS TÉCNICAS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Criar atalho na Área de Trabalho:
─────────────────────────────────
1. Clique com botão direito no QR-Code.bat
2. Selecione "Enviar para" → "Área de trabalho (criar atalho)"
3. Pronto!


Renomear o atalho:
─────────────────────────────────
1. Clique com botão direito no atalho
2. Selecione "Renomear"
3. Digite: "Meu QR Code"


Fixar na Barra de Tarefas:
─────────────────────────────────
1. Clique com botão direito no QR-Code.bat
2. Selecione "Fixar na barra de tarefas"
3. Pronto!

Problema: O arquivo não abre
Solução:  Clique com botão direito → "Abrir com" → Microsoft Edge


Problema: O QR Code não aparece
Solução:  Verifique se digitou algo na caixa de texto


Problema: Não consigo salvar
Solução:  Tente salvar na Área de Trabalho (é mais fácil de encontrar)


Problema: O antivírus reclamou
Solução:  Isso NÃO deve acontecer! Se acontecer, use o arquivo .hta


Problema: Preciso de ajuda
Solução:  Mostre o GUIA_VISUAL.txt para um familiar
