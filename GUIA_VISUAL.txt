┌────────────────────────────────────────────────────────────────┐
│  PASSO 1: ENCONTRAR OS ARQUIVOS                                │
└────────────────────────────────────────────────────────────────┘

Você precisa ter estes 2 arquivos na mesma pasta:

    📄 QR-Code.bat          ← CLIQUE AQUI!
    📄 QR-Code-App.html     ← (este fica junto)


┌────────────────────────────────────────────────────────────────┐
│  PASSO 2: ABRIR O PROGRAMA                                     │
└────────────────────────────────────────────────────────────────┘

    👉 Dê DOIS CLIQUES rápidos em: QR-Code.bat
    
    (Clique-clique com o botão esquerdo do mouse)


┌────────────────────────────────────────────────────────────────┐
│  PASSO 3: USAR O PROGRAMA                                        │
└────────────────────────────────────────────────────────────────┘

    Uma janela bonita vai abrir com fundo roxo!

    ┌─────────────────────────────────────────────────────────┐
    │  1️⃣  DIGITE o que você quer no QR Code                 │
    │     (na caixa de texto grande à esquerda)               │
    │                                                          │
    │  2️⃣  CLIQUE no botão roxo: "⚡ Gerar QR Code"          │
    │                                                          │
    │  3️⃣  O QR Code aparece na direita!                     │
    │                                                          │
    │  4️⃣  CLIQUE em: "💾 Salvar Imagem"                     │
    │     para salvar o QR Code                               │
    └─────────────────────────────────────────────────────────┘


┌────────────────────────────────────────────────────────────────┐
│  PASSO 4: PRONTO!                                               │
└────────────────────────────────────────────────────────────────┘

    ✅ Seu QR Code está salvo!
    
    Você pode:
    • Imprimir
    • Enviar por WhatsApp
    • Enviar por e-mail
    • Mostrar na tela do celular

┌────────────────────────────────────────────────────────────────┐
│  🎨 MUDAR AS CORES DO QR CODE                                  │
└────────────────────────────────────────────────────────────────┘

    Quer um QR Code colorido?

    1. Clique nas bolinhas coloridas (Roxo, Verde, Vermelho, etc.)
    2. O QR Code muda de cor automaticamente!

    📱 Telefone
    👤 Contato completo
    💬 SMS

┌────────────────────────────────────────────────────────────────┐
│  📝 EXEMPLOS DE USO                                             │
└────────────────────────────────────────────────────────────────┘

    EXEMPLO 1: QR Code para um site
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Digite: https://www.google.com
    Clique em "Gerar QR Code"
    Salve a imagem
    Pronto!


    EXEMPLO 2: QR Code para Wi-Fi
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Clique no botão "📶 Wi-Fi"
    Mude "NomeDaRede" para o nome do seu Wi-Fi
    Mude "Senha" para a senha do seu Wi-Fi
    Clique em "Gerar QR Code"
    Pronto!


    EXEMPLO 3: QR Code com seu telefone
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Clique no botão "📱 Telefone"
    Mude o número para o seu telefone
    Clique em "Gerar QR Code"
    Pronto!
